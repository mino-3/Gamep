이 코드는 Windows 콘솔 환경에서 키보드의 방향키(↑, ↓, ←, →)를 이용해 문자('A')를 자유롭게 이동시키는 인터랙티브 프로그램의 기본 템플릿입니다.

코드의 핵심 구조와 동작 방식을 체계적으로 정리해 드립니다.

1. 프로그램 개요
목적: 사용자의 키보드 입력을 실시간으로 감지하여 콘솔 창 내에서 캐릭터(문자)를 움직이는 애니메이션 효과 구현

종료 조건: 키보드의 Esc 키(아스키코드 27)를 누르면 반복문이 종료되며 프로그램이 닫힙니다.

2. 주요 함수 및 구성 요소
main 함수:

초기 좌표를 x = 10, y = 5로 설정합니다.

do-while 루프 안에서 화면 출력 ➔ 키 입력 대기 ➔ 좌표 갱신 ➔ 화면 청소 과정을 반복합니다.

gotoxy(int x, int y):

Windows API(SetConsoleCursorPosition)를 활용하여 콘솔 창 내 원하는 행/열 좌표로 커서를 이동시킵니다.

move_arrow_key(...):

입력된 키 값에 따라 x와 y의 값을 변경하며, 창 바깥으로 나가지 않도록 최소/최대 경계(1 ~ X_MAX/Y_MAX)를 검사합니다.

3. 핵심 동작 원리
즉시 입력 감지 (getch): <conio.h>의 getch() 함수를 사용하여 엔터(Enter)를 누르지 않아도 키를 누르는 즉시 값을 받아옵니다.

화면 갱신 (system("cls")): 사용자가 움직일 때마다 기존 화면을 깨끗이 지우고(cls) 새로운 위치에 'A'를 다시 그려 마치 움직이는 듯한 시각적 효과를 줍니다.

좌표 비율 맞춤 (x축 $\pm 2)**: 콘솔 글꼴의 세로가 긴 특성을 고려하여 좌우 이동 시 x` 좌표를 2칸씩 움직여 정사각형 모양의 이동 반경을 유지합니다.
