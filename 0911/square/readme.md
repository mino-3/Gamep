# C언어 콘솔 정사각형 그리기 프로그램 (Console Square Drawer)

Windows 콘솔 환경에서 사용자가 입력한 크기에 맞춰 특수 문자(박스 드로잉 문자)를 이용해 화면에 예쁜 정사각형을 그리고, `Esc` 키를 누를 때까지 프로그램을 유지하는 C언어 프로그램입니다.

---

## 🕹️ 기능 및 특징
* **정사각형 그리기**: 사용자가 입력한 길이(`size`)에 맞춰 상단, 중간, 하단 테두리를 출력합니다.
* **비율 보정**: 콘솔 창 글꼴의 세로가 긴 특성을 고려하여 가로 길이를 세로의 2배(`size * 2`)로 설정해 시각적인 정사각형 비율을 맞춥니다.
* **종료 대기**: 박스를 그린 뒤 `Esc` 키(아스키코드 27)가 입력될 때까지 안전하게 대기합니다.

🔍 핵심 코드 설명

박스 드로잉 문자 (0xa6 및 배열 b)

Windows 콘솔(CP949/EUC-KR 인코딩) 환경에서 모서리와 선 모양 문자(┌, ─, │, ┘ 등)를 조합하여 테두리를 완성합니다.

getch()를 이용한 종료 처리

<conio.h>의 getch() 함수를 사용하여 엔터 입력 없이 사용자가 누르는 키 값을 실시간으로 확인하고, Esc(값 27)가 입력되면 루프를 탈출해 프로그램을 종료합니다.

⚠️ 실행 환경 주의사항
본 코드는 Windows 운영체제(Visual Studio, Dev-C++ 등)의 명령 프롬프트(CMD) 환경 및 CP949 인코딩을 기준으로 작성되었습니다. 유니코드(UTF-8) 환경에서는 선 문자가 깨질 수 있습니다.
